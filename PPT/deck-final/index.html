訪談醫師後歸納出新手家醫的三個卡關：筆記找不到、少見病灶選藥靠經驗、長輩聽不懂醫囑。對應三個功能：學習庫、病歷與開藥、衛教單。所有寫入病歷或交給病人的內容，都由醫師確認。

來自醫師回饋的三個設計

病人歸檔

選「回診病人」，自動帶入年齡、過敏與過去就診，不用每次重打

醫師試用回饋

症狀也能開藥

除了依診斷推薦，現病史的症狀也會補上對症藥；頻率、天數、劑量都能自訂

受訪者回饋

圖卡式衛教單

每個重點一張插圖＋5–10 字短標語，插圖人物依病人的年齡與性別繪製

28 種常見問題＋10 種症狀 病歷可手動輸入或語音看診 學習庫語意搜尋 線上版 family-med-assistant.vercel.app
新手家醫看診助手03 / 07

新手家醫看診助手05 / 07
使用者用瀏覽器打開 family-med-assistant.vercel.app。Vercel 在首爾機房以無伺服器函式執行 FastAPI 後端與前端網頁；需要 AI 時呼叫 Gemini API；病歷、學習庫與衛教單存在 Supabase Postgres，圖片與錄音由瀏覽器直接上傳到 Supabase Storage，網站以有時效的簽名網址顯示；藥品參考表是整理好的政府開放資料，隨程式一起部署。程式推送到 GitHub 後由 Vercel 自動部署，金鑰只放在環境變數。
